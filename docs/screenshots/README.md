# Application screenshots

These screenshots show the production SlotForge Timing 1.99.1 UI with sample club-race data in an isolated Electron profile. No personal database or physical timing hardware was used.

- `home.png`: Home, with a four-lane grid, track record and previous race.
- `fuel.png`, `tyre-wear.png`, `weather.png`: the actual system editors, cropped to their dialog frames. Folders and sections were selected using the existing UI.
- `widget-builder.png`: a reusable driver card in the free-canvas Widget Builder.
- `audio-calls.png`: a low-fuel call in Custom Audio Settings.
- `help.png`: the Help page and its getting-started guidance.

PNGs are losslessly optimized; screenshot pixels are unchanged. The main README links each preview to its full-size image.
