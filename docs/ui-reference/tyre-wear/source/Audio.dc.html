When the wear levels are called
Calls at% life left
These are the same levels as in the Tyre Wear System (Rules board), so every race system can have its own. Every level is said once per set of tyres, not again after the same level.
Words that fill in by themselves
{left} says “14 laps” in a lap race and “205 metres” (or feet) in a Distance Race. {tyre} is the name of the tyre, like Soft or Intermediate. {sets} is how many sets that tyre has left. Time Token Sessions have no tyre wear, so these calls are never said there.
