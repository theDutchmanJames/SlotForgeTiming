SlotForge Circuit 0.3.16 integration runtime, supplied by the project owner
from the local SlotForge Track Builder source tree (1 November 2026).

integration.js, core.js, geometry.js, geometry.cjs, routed.js, routed-spline.js,
freeform.js, elevation.js and table-shape.js are the supplied runtime.
The only vendor changes are core.js and routed.js CommonJS geometry paths,
adjusted to ./geometry.cjs. Browser order: geometry.js, table-shape.js,
elevation.js, routed-spline.js, routed.js, freeform.js, core.js, integration.js.

No external npm runtime dependencies. Contracts 1.0.0-draft.1 through draft.10
and documented legacy v1 inputs are supported. Source geometry is validated
and regenerated; supplied caches are not trusted. The elevation module is a
required dependency of Circuit's geometry runtime, not a Timing 3D feature.
Live Tracker uses 2D lane paths, with sensor crossings authoritative for laps.
Circuit design identities remain separate from Timing's database track IDs.
